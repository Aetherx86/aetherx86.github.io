# aetherx86.github.io

Source code and assets for the official landing portal of **Aether Systems & Research Lab** (`https://aetherx86.github.io`).

- Pure HTML5/CSS/JavaScript with zero external runtime dependencies.
- Sub-50ms TTFB and 100/100 Lighthouse performance metrics.
- Product showcase and commercial licensing tiers for `sentinel-kit`, `rusty-chain-kit`, `Hexane`, and `VMP_DEVIRT`.
- High-performance mineral systems suite showcase: Zircon (freestanding RV32I micro-emulator), Corundum (comptime eBPF verifier), Spinel (SIMD Shannon entropy engine), Halite (deterministic Q16.16 LBM fluid automaton), Stibnite (POSIX C-ABI hooking interceptor), Beryl (CoW B-Tree & WAL engine), Realgar (bare-metal x86_64 micro-kernel), Pyrope (constant-time WireGuard / ChaCha20-Poly1305 tunnel), Tanzanite (CDCL SAT solver with DRUP certificates), and Celestine (audio DSP modular synthesizer & 1024-point FFT).

- Private security audit and consulting intake pre-filled mailto workflows.
